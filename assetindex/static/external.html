素材库 / 外部素材

看中了点开，选规格下载到素材库的 _下载。Poly Haven、ambientCG 都是 CC0；其他网站授权各异，详情里看（要署名的会给出署名文字）；itch.io 只按英文标签列免费素材，要到原页面手动下载。

这些网站只认英文：试试 bricks、grass、rock、wood、sky、sword、pixel art。

下载到素材库

    网站账号

    这几个网站要你自己账号的 key（注册免费）。key 只保存在服务器上，不会再显示出来；留空不改，要删掉就勾「清除」。

    下载模型要用（搜索不用）。登录 sketchfab.com → 头像 → Settings → Password & API → API Token。

    搜索就要用。登录 freesound.org 后打开 freesound.org/apiv2/apply 申请，填好后复制 “Client secret/Api key” 那一栏。

    搜索和下载都要用。登录 poly.pizza 后打开 poly.pizza/settings/api，新建一个应用，复制它的 API key。

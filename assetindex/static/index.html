看图模型

一个能看图的模型（OpenAI 兼容的 chat 接口，比如 Strata 上的 Qwen）。「看图描述」和「素材整理」都用它。

key 只保存在服务器上，不会再显示出来。改了接口地址要重新填 key。

任务参数（下次开始任务时生效）

素材整理同时发给模型几个问题。模型服务器本身开了并行才会更快，否则只是排队。

接口连不上、超时时，同一个包最多再问几次，之后记为失败（素材整理）。

接口出错后，等多久再给模型发新问题（素材整理）。

连续失败这么多次（答不出或接口出错）就停止任务，看图描述和素材整理都用。

语义搜索（向量模型）

OpenAI 兼容的 embeddings 接口（比如 Ollama 的 bge-m3）。搜索框按意思找资源包就靠它。扫描时会把每个素材的路径和描述发给这个接口。

key 只保存在服务器上，不会再显示出来。改了接口地址要重新填 key。换了模型，向量要全部重新算。

看图描述

让一个能看图的模型（OpenAI 兼容的 chat 接口，比如 Strata 上的 Qwen）给图片写一句中文描述和关键词。写好后，搜索框能按画面内容找到图片。每张图要几秒，只在你点「开始」时才跑。模型在右上角「设置」里设置。

还没设置看图模型：先点右上角「设置」。

下载到素材库

贴一个文件的下载链接，服务器用 aria2 下载到素材库的 _下载 文件夹，下完自动扫描，之后在「整理」里给它分类。文件大小不限；库里已有一模一样的文件时照样保留，标成「库里已有」，删不删你决定。
